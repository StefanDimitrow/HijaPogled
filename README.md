HijaPogled
HijaPogled is a Single Page Application (SPA) created using HTML and CSS, designed to provide a seamless, interactive user experience. The app is hosted on Firebase for easy deployment and global access.

HijaPogled is a lightweight, fast-loading web application built entirely with HTML and CSS. It is designed to be minimal yet elegant, delivering a smooth experience for users on both desktop and mobile devices. The application is hosted on Firebase, ensuring fast, reliable, and secure access.

Technologies Used
HTML – The core structure of the webpage.
CSS – Styling to make the app responsive and visually appealing.
Firebase – Hosting and deployment platform to host the application for global access.
Features
Single Page Application (SPA) with smooth navigation.
Fully responsive layout that adapts to different screen sizes.
Easy-to-read code structure with HTML and CSS.
Deployed on Firebase for fast access and updates.
